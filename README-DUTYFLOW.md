# DutyFlow v3.0 — Staff Duty & Attendance Management

A responsive, browser-based Duty Management System for employees, attendance, scheduling and leave management.

## Included
- Login demo (`admin` / `admin123`)
- Dashboard with attendance KPIs
- Employee management and departments
- Attendance records with clock in/out, hours and GPS capture
- Monthly duty roster
- Recurring shifts and auto scheduling
- Monthly calendar
- Leave requests and approvals
- Reports and CSV export
- JSON backup/restore
- Print/PDF via browser print
- WhatsApp roster sharing
- Responsive mobile layout
- Local persistence using `localStorage`

## Production upgrade
The current page is a frontend application suitable for GitHub Pages and demos. For secure production use, connect the UI to a backend API and PostgreSQL (or another managed database) for multi-user authentication, role-based permissions, cloud synchronization, audit history, server-side attendance validation, email/WhatsApp integrations and secure backups.
